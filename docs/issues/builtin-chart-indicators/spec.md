# K 线内置指标

用户要求将讨论的 MA、EMA、布林带、MACD、RSI 和成交量内置到现有 K 线图，直接选择使用。沿用现有图表与回放，是前端局部扩展。

## 行为

- 图表工具栏提供“指标”入口，参考 TradingView 的搜索列表，支持中英文搜索、分类、收藏和点击添加；每类指标保留一个实例，已添加状态明确显示。
- 默认 EMA20 与成交量开启；MA20、BOLL(20, 2)、MACD(12, 26, 9)、RSI14 关闭。顶部快捷开关位置以 2026-10-16 修订为准。
- MA、EMA、BOLL 叠加在价格主图；成交量沿用主图底部；MACD、RSI 使用共享时间轴的独立副图。
- 图内图例显示名称、参数和当前十字线对应值；离开图表显示最新值，缺少数据或尚未成熟显示破折号。主图、副图分别显示自己的图例。
- 图例提供隐藏/显示、设置、删除；隐藏保留指标与副图，删除移除实例。主图图例避开回放标题、快捷交易控件。
- 单个指标设置分为“参数、样式、可见性”，支持周期、颜色、线宽和显示周期选择；每项设置实际影响图表。
- 参数修改通过“应用”生效；取消或 Escape 丢弃草稿，恢复当前指标默认值需要应用。参数校验失败保留草稿并提示。
- 选择与参数保存在当前浏览器，刷新或重新进入图表可恢复；存储无效或不可用时使用默认值，操作仍可用。
- 设置升级到 v2，读取有效 v1 时保留已有选择、参数和颜色；收藏独立保存。
- 指标仅使用传给图表的当前行情；回放、分析后逐根查看、切换品种/周期、补历史和行情修正都重新计算。关闭指标不重置可视时间范围。

## 计算口径

- MA 使用收盘价简单移动平均；EMA 用第一段完整周期的 SMA 初始化。
- BOLL 使用收盘价 MA 和总体标准差；倍数范围 `(0, 10]`。
- MACD 的 DIF 为快慢 EMA 之差，DEA 为 DIF 的 EMA，柱值为 `2 × (DIF − DEA)`。
- RSI 使用 Wilder 平滑；连续上涨为 100，连续下跌为 0，全平为 50。
- 周期均为 1–500 的整数，MACD 快线周期必须小于慢线。样本不足时不绘制未成熟的值。

## 验收

1. 打开指标面板，选择并调整 MA 周期后，主图显示对应均线，刷新设置保留。
2. 同时开启 MACD、RSI 时分别显示在副图，关闭任一副图不影响蜡烛、其他指标或持仓覆盖层。
3. 非法参数不应用；取消不改变现有指标；存储被禁用时仍可操作。
4. 回放中的所有指标点不晚于当前进度，逐根推进与退出回放后恢复正确。
5. 空数据清空指标；补历史、修正同时间戳数据、切换周期不会保留旧值。

本期无需后端或 API 修改，不新增依赖。设置按浏览器保存，不提供账户同步或自定义脚本。
