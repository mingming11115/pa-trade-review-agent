# 同品种多周期图表与画线

状态：2026-10-18 用户在确认 Lightweight Charts 多图和画线插件路线后明确要求“实现”，进入实施。

日期：2026-10-18。

## 最新纠正：优先官方，保留完整功能

用户明确纠正“你不能给我删掉啊”。此前把“都用官方插件”解释为删除完整画线工具栏是错误的，本节替代该解释，无需再次请求批准。

恢复 `lightweight-charts-drawing 0.6.2` 与同版本上游 demo 原始 UI，保留全部 86 工具、文字／表格、图片、导入导出、旧标注的显示及编辑。官方竖线插件继续用于非活动图的只读竖线显示；其他标注与活动图编辑使用原画线引擎。旧标注与图片数据保留，指标、重置、多图、回放、保存／继续、开平仓及账户入口均不得因缺少官方成品而删除。

官方有等价组件时优先采用；没有时保留已有实现，并如实说明来源。

## 已确认的需求

- 多图和画线都是必需功能。
- 优先免费、开源方案，接受一次完整集成开发。
- 多图用于同一品种的多个周期，例如 ES 的 1m、5m、15m、1h。
- 复用现成图表的画线交互，减少逐项仿制图表功能的开发。

以下行为沿用讨论中的默认值；技术路线按用户最终确认改为保留 Lightweight Charts。

## 用户可见行为

### 布局与活动图

- 用户要求绘图区与原版工具栏背景一致：整个图表区域使用官方 demo 深色配色，包括绘图区、坐标轴、网格、图内图例与 PA 图表控制区；不修改上游原版 UI 文件。
- 桌面首次使用默认四图，按两行两列显示 1m、5m、15m、1h。
- 提供单图、左右双图、四图切换。切换布局保留各槽位的周期、指标和画线；隐藏槽位不继续创建请求或渲染实例。
- 所有图共享品种选择。切换 ES / NQ 等品种时整组切换，并读取该品种自己的画线。
- 每张图有独立周期选择，周期范围沿用 PA 现有选项。
- 点击图表使其成为活动图，以边框和周期标题标识。公共指标设置及绘图工具作用于活动图。
- 单图显示当前活动图；双图显示当前活动图及另一个保留槽位。恢复四图时还原槽位顺序。
- 窄屏默认只显示活动图，以周期标签切换；放大单图和退出放大不删除其他图的配置。
- 布局、槽位周期和联动开关在当前浏览器保存，按登录用户隔离；未登录沿用 local 作用域。

### 多周期联动

- 四图使用同一时区显示，内部以 UTC 时间戳关联。
- 十字线联动默认开启。源图指向某个时刻时，其他周期定位到包含该时刻的 K 线，并显示各自周期的 OHLC；不复制源图的 OHLC。
- 目标周期没有对应行情时隐藏该图的联动提示，不用相邻 K 线冒充对应数据。
- 时间定位联动默认开启：拖动后共享时间锚点，各图保留自己的时间跨度和柱宽，适合同时观察分钟细节与小时结构。
- 缩放保持各图独立。时间定位与十字线联动可分别关闭。
- 相同柱数在不同周期对应不同历史跨度。联动超出已加载范围时，只在已有历史加载上限内补读；仍不可达时保留范围边界提示，不伪造 K 线。
- 联动事件带来源标识，合并到动画帧处理，避免互相触发循环。

### 画线与保存

- 用户进一步明确：有上游实现的组件必须直接使用原始实现，不接受自制简化工具栏。画线 UI 改为官方 demo 0.6.2 源码接入，完整保留 86 工具、SVG、分组菜单和编辑交互；宿主只适配数据、生命周期、隔离和持久化。没有上游成品的 PA 多图、指标面板和交易组件须明确标注来源，详见 component-audit.md。
- 2026-10-18 用户要求画线工具放在侧边：活动图左侧显示独立竖排图标栏，悬停显示名称；属性面板向右展开，不再在图内底部堆叠工具按钮。
- 首批完整支持水平线、趋势线段、射线、矩形、斐波那契回撤和文字标注。
- 支持选择、拖动锚点、修改颜色/线宽、锁定和删除；Esc 取消未完成绘图或当前拖动。
- 默认同品种跨周期共享画线，也可将单个标注设为仅当前周期显示。
- 画线保存原始 UTC 时间和价格锚点，不保存屏幕像素或某个周期的柱序号。周期切换只改变投影，不改写原始锚点；聚合后落在同一根 K 线的多个锚点允许在该周期重叠。
- 同一共享画线只有一个业务 ID。在任一周期修改或删除后，其他图同步更新，不生成重复副本。
- 普通行情按用户和品种保存；回放按用户和场次独立保存，避免普通行情中事后绘制的标注进入历史训练。
- 回放标注记录创建、修改、删除对应的回放游标。历史回看只显示该时刻已存在的标注版本；射线向右延伸属于用户预测，不读取未来行情。
- 本期保存在当前浏览器，不提供跨设备同步。存储格式带版本号，只序列化工具类型、锚点、样式、文字、可见性及回放修订信息。
- 完成绘图或拖动后自动保存；存储不可用时保留内存中的标注并明确显示“未能保存到此浏览器”，允许继续操作。
- 保存回放成功后，以返回的保存版本 ID 保存本地标注快照；从该版本继续回放时复制到新草稿。放弃新草稿不覆盖原版本标注。

### 回放与图上交易

- 只保留一个回放会话、一个播放时钟、一个观察游标和一套订单/账户状态。
- 底部统一提供播放、下一根、推进周期、回放时间及退出。推进周期默认 1m，可使用现有周期选项；改变活动图或显示周期不改变推进周期。
- 每次推进或历史回看后，所有可见图使用同一明确的截止游标请求对应周期行情。
- 高周期当前柱可动态形成，并标识未收盘；它的 OHLC 和成交量只包含截止游标以前已完成、已确认的分钟数据。
- 例：回放到 10:07，5m 的 10:05 柱只含 10:05、10:06 两根分钟；1h 的 10:00 柱只含 10:00–10:06。不能显示 10:07 以后分钟的高低点、收盘或成交量。
- 一次推进只发送一个 advance 命令，撮合继续由后端逐分钟处理。
- 一批图表数据全部就绪后统一提交画面与成交标记，避免不同周期显示不同进度。
- 某周期加载失败时暂停播放，保留上一完整图表批次，并显示图表截止时间及重试入口；服务端已成功的交易或推进不回滚，也不重复提交。
- 数据未追上最新会话状态时禁止图上下单和保护价编辑，并隐藏可能与旧行情错配的交易覆盖层；完成刷新后恢复。
- 成交标记映射到各自周期对应的 K 线。活动图显示 BUY / SELL、持仓操作和可编辑止盈止损；其他图可展示同一持仓的只读价格线。
- 绘图、选回放起点和拖动保护价互斥；开始绘图或编辑时暂停播放。空白区右键沿用下单/重置视图，标注上的右键用于标注操作，禁止库默认右键直接删线。
- 回看仍只观察历史，不撤销成交；回到最新进度后恢复交易能力。

### 指标与分析兼容

- 各图指标独立配置，沿用已有指标面板、参数、样式、可见性和收藏行为。
- 保留当前 MA/EMA/BOLL/MACD/RSI/VOL 的计算口径，尤其是 MACD 柱值的 2 倍系数和 RSI 的 Wilder 平滑，不因换库改用不同算法。
- Gap、K#、H/L 等 PA 叠加按所在图的周期和可见行情计算。
- 已有分析结果只在匹配其来源周期的图上呈现，注明分析截止时间；切换活动图不自动调用模型。
- 新发起的分析使用活动图的品种、周期及现有分析时间选择流程，提交前的界面上下文与实际请求一致。

## 技术方案

### 选型

保留项目现有 `lightweight-charts ^5.2.0`，接入用户试看的 MIT 开源画线插件 `lightweight-charts-drawing 0.6.2`（peer dependency 为 `lightweight-charts ^5.0.0`）。用户在查看插件、多图能力及集成路线后明确要求“实现”，本次授权覆盖该插件接入。保留 PA 已有指标、回放和交易覆盖层，避免迁移整套图表引擎。

PA 负责分屏、跨周期时间映射、共享标注模型和本地持久化；画线选点、拖动、命中测试与渲染使用插件。通过公开 API 接入，不读取库私有字段。插件用项目包管理器安装并锁定确切版本，禁用依赖安装脚本。

实施在当前工作目录进行，保留用户当前文件和环境，不执行提交、合并或发布。

### 前端职责

- 图表接入：在现有 `TradingChart` 和 `ChartOverlayContext` 上增加可选画线及联动注册入口，保留现有坐标与交易覆盖层接口。
- 多图工作台：管理布局、活动图、槽位周期及共享工具栏，不持有独立订单或回放时钟。
- 联动协调器：处理时间定位、十字线和标注广播，统一 UTC 锚点及来源去重。
- 多周期数据协调：在现有行情/回放状态来源上扩展可见周期数据，不给每张图创建独立 `useReplaySession`。
- 标注存储：负责可序列化模型、作用域、版本校验、本地快照和恢复；不把图表实例或回调写入存储。
- 交易覆盖层：通过适配器获取坐标和锁定交互，保持原有下单、平仓、保护价和状态冲突检查。

主工作台普通行情、原图模拟交易回放和真实交易回放使用同一套多图协调。旧回放记录详情仍可单图展示，但使用同一底层适配器并保留成交及指标行为。

### 数据与后端契约

- 复用现有 `GET /api/v1/replay/sessions/{id}/bars?period=...&cursor=...&limit=...`。后端已支持按周期聚合并排除游标之后的分钟。
- 每批从一次确定的会话状态读取游标，四请求显式携带该游标，最大并发数为可见的不同周期数，最多 4。相同周期复用请求结果。
- 会话、品种、周期配置或观察游标变化时取消过期批次；迟到响应不能覆盖新数据。未显示的槽位不发请求。
- 前端补齐后端已有字段类型：`Bar.is_partial` 和回放 bars 响应的 `cursor`、`source`、`next_before`。这是已有契约类型化，不新增端点或数据库表。
- 默认每周期请求最近 120 根；加载更多最多 500 根，继续遵守后端 30 个自然日回溯边界。高周期不足时返回实际数据。
- 普通行情使用现有 market API 按相同截止时间读取各周期，不用仅有 120 根的 1m 样本直接拼出 120 根 1h 图。
- 回放推进、订单操作和事件分页每轮只执行一次，避免因四图重复处理同一批成交。

## BDD 验收场景

1. **四周期同屏**：给定 ES 行情，打开四图后看到 1m/5m/15m/1h；修改某槽位周期只改变该槽位，四图品种始终一致。
2. **布局恢复**：给定四图配置，放大 15m 再恢复四图、刷新页面，布局、周期和标注按保存值恢复。
3. **跨周期十字线**：指向 1m 的 10:07，5m 定位到 10:05、15m 和 1h 定位到各自时间桶，显示自己的 OHLC；缺失桶不显示错误值。
4. **独立观察跨度**：拖动时间锚点使其他图跟随定位；缩放 1m 不强制 1h 变成相同时间跨度，关闭联动后可独立拖动。
5. **共享画线**：在 5m 画趋势线，其他周期显示同 ID 的标注；拖动、样式修改和删除传播一次，切周期不漂移或复制。
6. **保存隔离**：ES 与 NQ、不同登录用户、普通行情与回放场次的画线互不串用；存储损坏或被禁用时可继续使用且显示未保存状态。
7. **回放无未来行情**：以固定分钟样本推进到 10:07，四周期只出现该时刻前已确认分钟聚合的值，当前高周期柱有未收盘标记，指标计算同样不含未来数据。
8. **回放无未来标注修订**：在后续进度创建/修改/删除标注后回看早期时刻，显示当时的版本；回到最新恢复对应版本。
9. **一份回放状态**：四图播放一轮只发一个推进命令；活动图切换不修改推进周期，不重复下单或生成事件。
10. **批次失败与竞态**：任一周期超时或失败，播放暂停并保留上一完整批次；切换场次后的旧响应不能污染新场次，重试不重复已成功命令。
11. **交易交互**：在活动图买卖、平仓、拖动 TP/SL 后，账户和各图价格线一致；取消绘图、切周期、切活动图及退出后没有残留拖动锁。
12. **已有能力回归**：原回放起点选择、保存/放弃/继续、真实成交回放、指标参数和 PA 分析叠加正常；已保存版本的本地标注随继续回放复制，放弃草稿不改原版本。
13. **正常行情及窄屏**：普通行情各周期来自同一截止上下文，活动图分析请求周期正确；窄窗口可切换完整单图，没有挤成不可操作的四个小画布。
